MCP Tool Integration

Integrate Vigil's security evaluation layer into your Kite workflows. This guide covers the core tools for evaluating risk before transaction execution and recording the outcome for continuous model training.

key Initializing the Agent Session

Before invoking Vigil tools, you must establish a secure agent session via the Kite CLI. This provisions the necessary cryptographic context for evaluating payments.

Terminal content_copy 
$ kpass agent:session create \
    --network=ethereum \
    --policy=strict_aml \
    --ttl=3600

policy Evaluating Payments evaluate_payment

The primary evaluation endpoint. It analyzes the transaction parameters against active Risk Models and returns a confidence score alongside a deterministic action (ALLOW, BLOCK, REQUIRE_AUTH). 

import { evaluate_payment } from '@vigil/mcp-tools';

const result = await evaluate_payment({
    target_address: "0x742d35Cc6634C0532925a3b844Bc454e4438f44e",
    amount: "1.5",
    currency: "ETH",
    context: {
        user_id: "usr_982bV",
        device_fingerprint: "x8f_991"
    }
});

/* 
Returns:
{
    "status": "CAUTION",
    "confidence_score": 72.4,
    "action": "REQUIRE_AUTH",
    "flags": ["NEW_DEVICE", "HIGH_VALUE"]
}
*/

database Recording Outcomes record_outcome

Crucial for model feedback. After a transaction is finalized (or fails), log the result. This data streams back to the Safety Logs and trains the continuous learning models. 

await record_outcome({
    eval_id: result.eval_id,
    tx_hash: "0xabc123...",
    status: "SUCCESS",
    gas_used: 21000
});
SYS-LOG-REQ CRITICAL PATH

Failure to record outcomes within 24 hours of an evaluation will degrade the precision of your tenant-specific risk models. Ensure this step is wrapped in robust error handling.
